# AI 導入課程與評量 —— AI 素養融入教學與學生學習的實務架構

> **主講人**：南投縣史港國民小學 **施君潔 主任**（教育部數位學習輔導專家 / 因材網國語文輔導委員）  
> **核心概念**：AI 是鷹架（Scaffold），不是拐杖（Crutch）· 捍衛學習者與教師的專業能動性

---

## 🌐 互動查詢網頁系統

- **訪問網址**：可直接開啟本專案之 `index.html` 或透過 GitHub Pages 瀏覽。
- **存取防護**：本系統設有授權門禁保護，請輸入內部密碼解鎖進入。

### 🌟 系統亮點功能
1. **即時分類與全文檢索**：支援關鍵字即時比對（如：鷹架、Bastani、提問、查證、換句話說、國語文）。
2. **學生課堂六部曲互動模擬器**：
   - 先想 ➔ 再問 ➔ 查證 ➔ 取捨 ➔ 揭露 ➔ 脫離
   - 內建教師提問口訣與一鍵複製適用 Prompt 模組。
3. **七項學習設計指標備課檢核器**：
   - 包含互動勾選清單，並內建「教師教學觀察與反思句型公式產生器」。
4. **Bloom-AI 認知層次防外包互動金字塔**：
   - 依據 Schober (2025) BLOOM-AI 模型，逐層揭示記憶、理解、應用、分析、評估、創造之「防外包準則」與國語文實務對照。
5. **教育部 AI 能力圖像三階段對比表**：
   - 完整比對國小（起步）、國中（深化）與高中（精進）之四大核心能力指標。
6. **Word 講義手冊一鍵下載**：
   - 點擊頂部按鈕即可下載重新排版之完整講義手冊 (`.docx`)。

## 💡 研習核心精神摘要

> **「先有主動、積極的態度，再有思考的方法，最後強化使用工具的技巧。」**

- **Bastani 等人 (2025)**：移除 AI 後，學生成績反而比未使用 AI 者低 17%；必須設有教學護欄。
- **Darvishi 等人 (2024)**：移除提示後學生無法維持表現，反映學生依賴 AI 而非策略內化。
- **Fan 等人 (2025)**：過度依賴 AI 減少規劃與監控活動，造成「後設認知懶惰」。
- **Dragan Gašević (2026)**：Ask what learners can do when AI support is reduced.
